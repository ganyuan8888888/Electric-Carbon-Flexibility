# Research releases and citation

Repository: https://github.com/ganyuan8888888/Electric-Carbon-Flexibility

Research scope:

> Process-executable electric-carbon flexibility, certified recovery trajectories, and two-stage robust industrial demand response.

1. Download a tagged release or clone the repository. The release includes all research models, numerical datasets, documentation, and configuration files. Reproduction outputs and local environments are excluded from version control.
2. Run the README quick-start commands and review `results/published/reproduction_validation.json` and the scientific protocol. The data inventory and release manifest identify each archived file and its checksum.
3. Select the license for the authors' original code and data. Preserve the RTS-GMLC third-party notice. The package does not assume permission to impose a new open-source license on all authors' work.
4. Cite the version used in your analysis using `CITATION.cff`. The actual repository URL is included; no DOI or publication identifier is assumed.
5. Version `v1.0.1` identifies the research collection with updated public documentation. Preserve versioned releases when reporting results. An archival service such as Zenodo or Mendeley Data can provide a DOI after deposition.
6. The data availability statement can link to the repository or to the specific version used in the study.

Official references: [GitHub large-file guidance](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github), [citation files](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files), and [repository licensing](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).
