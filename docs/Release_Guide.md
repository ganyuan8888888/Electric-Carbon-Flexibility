# Preparing the GitHub release

Suggested repository name: `Electric-Carbon-Flexibility`

Suggested description:

> Process-executable electric-carbon flexibility, certified recovery trajectories, and two-stage robust industrial demand response.

1. Create an empty GitHub repository with the name above. Upload the contents of this folder, including `README.md`, `CITATION.cff`, and hidden configuration files. Do not upload `reproduced/`, virtual environments, caches, or the enclosing ZIP as the only repository content.
2. Run the README quick-start commands and review `results/published/reproduction_validation.json` and the scientific protocol. The data inventory contains no individual file exceeding the browser's 25 MiB limit. For thousands of data files, GitHub Desktop or Git is more practical than a browser upload.
3. Select the license for the authors' original code and data. Preserve the RTS-GMLC third-party notice. The package does not assume permission to impose a new open-source license on all authors' work.
4. Add the actual repository URL to `CITATION.cff` and the README after upload. No fabricated DOI, ORCID, grant or publication identifier is included.
5. Create release `v1.0.0` for the submission snapshot. Keep later changes in new releases. An immutable archive with Zenodo or Mendeley Data can provide a versioned DOI. Add the DOI after it is issued.
6. Update the manuscript and submission-system data statement only after the URL is live and its intended visibility has been confirmed. The current manuscript statement is intentionally unchanged in this local preparation.

Official references: [GitHub large-file guidance](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github), [citation files](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files), and [repository licensing](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).
